# Práctica 2

Aqui se encontraran programas desarrollados en Java respecto a la Práctica 2 de la materia de Introduccion a Ciencias de la Computacion

* Cadenas.java 
* Civilizacion.java 
* Patrones.java 

## Compilación

Desde la terminal, dentro de la carpeta del proyecto, ejecutar:

javac Cadenas.java
javac Civilizacion.java
javac Patrones.java

## Ejecución

Para ejecutar el programa de cadenas:

- java Cadenas

Para ejecutar el programa de civilización:

- java Civilizacion

Para ejecutar el programa de patrones:

- java Patrones
